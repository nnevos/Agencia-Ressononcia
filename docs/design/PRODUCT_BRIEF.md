# RESSONÂNCIA — Product Brief consolidado

**Formato:** jogo web narrativo de gerenciamento de heróis + estratégia de despacho + visual novel/dating sim.

**Fantasia do jogador:** ser o Analista que conhece os heróis suficientemente bem para tomar decisões difíceis sob pressão — e depois precisa encará-los como pessoas.

**Frase-base:** “Gerencie pessoas extraordinárias em uma cidade que nunca espera você estar pronto.”

## Pilares
1. O jogador despacha; não controla diretamente o combate.
2. Administrar pessoas, não peças.
3. Composição importa mais que poder bruto.
4. Decisões deixam consequências.
5. Conhecer personagens é vantagem estratégica e narrativa.
6. Informação é imperfeita.
7. Dispatch e relações nunca devem parecer dois minigames independentes.

## Protagonista
Analista de Despacho nomeado pelo jogador. Não possui papel de “oitavo herói” e não substitui o protagonismo/história dos sete.

## Elenco
Yuki/Frio, Elysia/Energia, Lysandro/força+espada, Hélio/Fogo, Demétria/Terra, Alexandra/Água, Eros/Ar. Todos são rotas possíveis, mantendo personalidade e vínculos próprios.

## Tecnologia aprovada para a versão atual
Web-first: Next.js + React + TypeScript + CSS. Persistência local provisória; Supabase Auth/PostgreSQL previstos para fase posterior. Conteúdo narrativo deve migrar para dados estruturados.
